🚀 Hướng Dẫn Cài Đặt

1
Lấy API credentials từ Telegram

Truy cập my.telegram.org/apps → tạo App → lấy api_id và api_hash

2
Điền vào file .env 
TELETHON_API_ID=12345678
TELETHON_API_HASH=abcdef1234567890abcdef
TELETHON_PHONE=+84901234567
TELETHON_SESSION=session_main
3
Chạy lệnh xác thực một lần 
python3 forwarder/auth.py

Nhập mã OTP Telegram gửi về. File forwarder_state/session_main.session sẽ được tạo.

4
Khởi động lại web server 
python3 run.py

Web app sẽ tự nhận session file, không cần xác thực lại.

🔒
An toàn: API credentials và session file chỉ được lưu trên server của bạn. Không có dữ liệu nào được gửi đến bên thứ ba. Session file hoạt động như cookie đăng nhập — giữ nó bí mật.
